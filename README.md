# MyTube

Strona wzorowana na YouTube: lista filmów, wyszukiwarka, filtrowanie po kategoriach i menu boczne.

## Jak otworzyć

Otwórz plik **`index.html`** za pomocą Google Chrome
(prawy przycisk myszy na pliku → „Otwórz za pomocą" → Google Chrome).

## Pliki

- `index.html` – główna strona
- `css/style.css` – wygląd
- `js/script.js` – działanie (menu, wyszukiwarka, filtry)
- `img/` – obrazki i awatary

Do wyświetlenia czcionek i miniatur potrzebne jest połączenie z internetem.
